# Contributing to sandhan (সন্ধান)

Thank you for helping build a free, open, and private search engine for the world!

## Getting Started
1. Clone the repository
2. Run `npm install` inside `apps/web`
3. Run `npm run dev` to start the frontend interface
4. Test crypto, goggles, and i18n modules with `npm test`

## Contribution Tracks
- **Track A — Ranking & IR**: Relevance improvements, BM25 tuning, LTR models.
- **Track B — Bengali NLP**: Stemmers, stopword dictionaries, phonetic spellcheckers.
- **Track C — Interface & Accessibility**: WCAG 2.2 AA accessibility, responsive design, fast performance.
- **Track D — Small Web Crawling**: Discovering independent blogs and literary archives.

## Coding Standards
- All cryptography must adhere to zero-knowledge guarantees.
- Do not add any 3rd party trackers, ads, or fingerprinting scripts.
