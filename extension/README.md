# 🌐 সন্ধান ব্রাউজার এক্সটেনশন (Sandhan Browser Extension)

সন্ধান (Sandhan) — উন্মুক্ত, স্বাধীন ও গোপনীয় সার্চ ইঞ্জিনের জন্য অফিসিয়াল ব্রাউজার এক্সটেনশন (Manifest V3)।

---

## ✨ সুবিধাসমূহ:
1. **⚡ অমনিবক্স সার্চ (Omnibox Keyword `s`):**
   * ব্রাউজারের অ্যাড্রেস বারে `s` লিখে <kbd>Space</kbd> বা <kbd>Tab</kbd> চাপলেই সন্ধান সার্চ সক্রিয় হয়ে যাবে।
2. **🔍 দ্রুত পপআপ সার্চ (Popup Search):**
   * এক্সটেনশন আইকনে ক্লিক করে সরাসরি সার্চ, ক্যাটাগরি ফিল্টার এবং লাইভ প্রিভিউ দেখুন।
3. **🖱️ রাইট-ক্লিক মেনু (Context Menu Search):**
   * যেকোনো ওয়েব পেজের কোনো টেক্সট সিলেক্ট করে রাইট-ক্লিক করলেই সরাসরি সন্ধানে বা উইকিপিডিয়ায় খোঁজার অপশন পাওয়া যাবে।
4. **🚀 ব্যাং শর্টকাট (Bang Redirects):**
   * `!w` (উইকিপিডিয়া), `!g` (গুগল), `!gh` (গিটহাব), `!yt` (ইউটিউব) ইত্যাদির সাপোর্ট।
5. **⚙️ কাস্টমাইজেবল সেটিংস:**
   * ডিফল্ট ভাষা, লোকাল/লাইভ ইনস্ট্যান্স URL এবং নতুন ট্যাব প্রেফারেন্স কনফিগার করার সুবিধা।

---

## 🛠️ ইনস্টলেশন নির্দেশিকা (Chrome, Edge, Brave, Opera):

1. আপনার ব্রাউজারে এক্সটেনশন পেজে যান:
   * **Google Chrome / Brave:** `chrome://extensions/`
   * **Microsoft Edge:** `edge://extensions/`
   * **Opera:** `opera://extensions`
2. ওপরের ডানদিকের **"Developer mode"** (ডেভেলপার মোড) চালু (Toggle ON) করুন।
3. বামপাশে **"Load unpacked"** (লোড আনপ্যাকড) বাটনে ক্লিক করুন।
4. আপনার কম্পিউটারের এই ফোল্ডারটি সিলেক্ট করুন:
   ```
   c:\Users\joysr\Documents\web projects\sandhan\extension
   ```
5. ব্যাস! সন্ধান এক্সটেনশনটি সাথে সাথে ইনস্টল হয়ে যাবে এবং ব্রাউজার টুলবারে যুক্ত হবে।

---

## 💡 ব্যবহারের নিয়ম:
* **অ্যাড্রেস বার থেকে:** টাইপ করুন `s বাংলাদেশ` $\to$ <kbd>Enter</kbd>
* **টুলবার পপআপ থেকে:** এক্সটেনশনের সবুজ 'স' আইকনে ক্লিক করে সার্চ করুন।
* **সিলেক্ট করা টেক্সট থেকে:** যেকোনো টেক্সট হাইলাইট করে রাইট-ক্লিক $\to$ *সন্ধানে খুঁজুন*।
