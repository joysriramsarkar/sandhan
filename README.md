**সন্ধান** একটি মুক্ত, স্বাধীন ও সম্পূর্ণ গোপনীয়তা-সুরক্ষিত সার্বজনীন সার্চ ইঞ্জিন — **[sandhan.site](https://sandhan.site)**। এটি সমগ্র বিশ্বের কোটি কোটি ওয়েবসাইট, উইকিপিডিয়া, ব্লগ ও সংবাদ মাধ্যম থেকে নিমেষেই তথ্য খুঁজে আনে। ব্যবহারকারীর অনুসন্ধানের ইতিহাস কোনো সার্ভারে জমা হয় না, বরং ব্যবহারকারীর নিজস্ব ব্রাউজারে মিলিটারী-গ্রেড ক্রিপ্টোগ্রাফির মাধ্যমে সম্পূর্ণ সুরক্ষিত থাকে।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ

- 🌐 **সার্বজনীন উন্মুক্ত ওয়েব অনুসন্ধান**: সমগ্র ইন্টারনেট থেকে যেকোনো ব্যক্তি, ওয়েবসাইট, তথ্যকোষ, কোড রিপোজিটরি, ছবি বা খবরের নির্ভরযোগ্য ফলাফল।
- 🔐 **শূন্য-জ্ঞান এনক্রিপশন (Zero-Knowledge)**: আপনার সার্চ হিস্টরি ব্রাউজারেই **AES-256-GCM** অ্যালগরিদম দিয়ে এনক্রিপ্ট হয়ে থাকে। পাসফ্রেজ ছাড়া সার্ভার বা কোনো তৃতীয় পক্ষের পক্ষে তা পড়া অসম্ভব।
- 📱 **মোবাইল ও রেসপন্সিভ ইন্টারফেস**: স্মার্টফোন, ট্যাবলেট কিংবা কম্পিউটার — সব ডিভাইসের জন্য বিশেষ অপ্টিমাইজড ও মসৃণ লেআউট।
- 👓 **স্বচ্ছ র‍্যাংকিং ও গগলস (Goggles)**: প্রতিটি ফলাফলের পাশে "কেন এই ফলাফল?" বোতাম চেপে র‍্যাংকিং সিগন্যাল বিশ্লেষণ দেখুন এবং নিজস্ব নিয়মে ফলাফল সাজান।
- ⚡ **তাৎক্ষণিক উত্তর ও ক্যালকুলেটর**: বাংলা ও ইংরেজি সংখ্যা সমর্থিত গণিত সমাধানকারী, একক রূপান্তর এবং দ্রুত ব্যাং শর্টকাট (`!w`, `!gh`, `!yt`, `!ddg`, `!g`)।
- 📚 **উইকি জ্ঞানকোষ প্যানেল**: নির্বাচিত ভাষার উইকিপিডিয়া থেকে তাৎক্ষণিক সারসংক্ষেপ ও তথ্যপ্যানেল।
- ⚖️ **মানব-মূল্যায়ন প্ল্যাটফর্ম (`/judge`)**: ব্যবহারকারীর পরিচয় গোপন রেখে অনুসন্ধানের প্রাসঙ্গিকতা যাচাই ও মানোন্নয়নের উন্মুক্ত ব্যবস্থা।
- 📊 **টেলিমেট্রি ড্যাশবোর্ড (`/dashboard`)**: ডিফারেনশিয়াল-প্রাইভেসি সুরক্ষিত লাইভ পরিসংখ্যান।

│   └── indexer/                       # ইনভার্টেড ইনডেক্সার

## 🚀 দ্রুত শুরু

### লোকাল ডেভেলপমেন্ট
```bash
# ডিপেন্ডেন্সি ইনস্টল
cd apps/web
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev
```
ব্রাউজারে খুলুন: **`http://localhost:5173`**

### টেস্ট ও বেঞ্চমার্ক
```bash
# ইউনিট টেস্ট
cd apps/web && npm test

# বানান মূল্যায়ন
python eval/typo_bench.py

# প্রাসঙ্গিকতা বেঞ্চমার্ক
python eval/bench.py
```
